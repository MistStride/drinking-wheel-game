📖 自定义你的题库

不想用官方那 646 道题？三种方式给你的转盘换上专属题目，从最省事到最自由：

① 在界面上一条条加（最推荐，零基础）
  1. 点右上角 ⚙️ 设置 → 打开「⑥ 题库编辑」。
  2. 在粉色「＋ 新增题目」框里写题干，选好分类（真心话/大冒险/直接喝/深度聊）。
  3. 大冒险再选个尺度；真心话/深度聊再选个话题范围。
  4. 点 ＋ 新增，题目立刻进转盘，不用刷新。
  5. 想隐藏某题：在下方列表取消它的「用」勾选即可。
② 复制一段话给 AI，一键生成整套题库

把一份现成的「需求模板」复制给任意 AI（网页版 / 微信 AI 助手都行），它就会吐出一个可直接导入的题库文件。模板和填法都在这份指南里。

③ 在官方题库上加菜

先导出官方题库，让 AI 在里面追加你自己的梗（保留原题），再导回应用。适合「喜欢官方题、只想补几条」的情况。

📥 怎么把自定义题库用起来

无论上面哪种方式，最后都是拿到一个 .json 文件 → 在「⑥ 题库编辑」点 ⬇ 导入 JSON 即可。注意：导入会整体覆盖当前题库，换之前记得先点 ⬆ 导出 JSON 备份。

⚖️ 自定义抽题比例

「按题目」模式下，可为每个二级分支单独设定放进转盘的题目数量（不超过右侧上限）。留空或 0 表示不放该类。
