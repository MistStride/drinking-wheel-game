# 🍻 喝酒大转盘（单文件版）

一个开箱即用的网页版随机转盘，专为聚会设计。双击 `app.html` 即可在浏览器里玩 —— **无需安装、无需服务器**，题库 1148 题已内联，抽题、暗箱、去重全部在前端完成。

> ⚠️ 使用前请确保所有参与者知情且自愿参与，并自觉把握玩笑尺度。

---

## ✨ 功能特性

- **四大玩法**：真心话 / 大冒险 / 直接喝 / Deeptalk，转盘配色一目了然。
- **两种转盘模式**
  - **按类型（分支）**：每格是一个类别，停下后在该类里随机抽一道题。
  - **按题目**：按类别比例从生效题中随机抽若干道（默认 50，可改）放进转盘，停下直接显示原题。
- **精准暗箱**：可指定「第 N 次」或「前 K 次」必中某个类别，甚至必中**某一道具体题目**（搜索题干后指定）。暗箱指定的题会强制进入转盘，确保按设定命中。
- **不重复抽取**：关闭「允许重复抽取」后，抽中的题会从转盘移除、下次不会再中（暗箱保护的题除外）；可一键「重置已抽」。
- **限制级模式**：解锁前任 / 亲密·情欲暧昧 / 身体探索 / 亲密接触 等 spicy 内容（默认关闭）。
- **题库可外部编辑**：随时导出 JSON（无损）或 CSV（方便用 Excel 改文字），改完再导入覆盖；也能直接改生成器重新批量生成。
- **糖果童趣 UI**：明亮柔和的粉 / 黄 / 浅蓝 / 淡紫配色，圆润动效，贴合派对氛围。

## 🚀 快速开始

**方式一（最简单）**：直接双击 `app.html`，用浏览器打开即可玩。

**方式二（开发者 / 二次构建）**：

```bash
node gen-bank.js   # 生成 question-bank.json（与 question-bank.js）
node build.js      # 把题库注入 app.src.html，生成自包含 app.html
```

> 需要本地安装 Node.js。生成器会重新批量生成并去重；构建脚本把题库内联进单文件。

## 🗂 项目结构

| 文件 | 说明 |
| --- | --- |
| `app.html` | **主程序**：自包含单文件，双击即玩 |
| `index.html` | 轻量 starter（内联配置，适合快速改类别） |
| `app.src.html` | 源码模板（含题库占位符），由 `build.js` 注入后产出 `app.html` |
| `gen-bank.js` | 题库生成器：模板 + 词池批量生成 1000+ 题，含去重 |
| `build.js` | 构建脚本：把题库注入 `app.src.html` 生成 `app.html` |
| `question-bank.json` | 题库数据（1148 题），可外部编辑后导入 |
| `question-bank-design.md` | 题库分类与字段设计文档 |

## 🛠 自定义题库

- **只改题目文字**：在应用里点「⑥ 题库编辑」，导出 JSON / CSV → 用编辑器或 Excel 改 → 再导入覆盖。
- **重做整套题库**：改 `gen-bank.js` 的模板与词池 → `node gen-bank.js` → `node build.js`。
- **调暗箱 / 比例 / 限制级**：对应逻辑在 `app.src.html` 的 `CAT_META` / `resolveRigging()`，改完重新 build 即可。

## 🔧 技术说明

- 转盘基于 [lucky-canvas](https://github.com/buuing/lucky-canvas)（通过 CDN 引入）。
- 题型、权重、暗箱命中逻辑见 `app.src.html` 的 `CAT_META` 与 `resolveRigging()`。
- 当前 `app.html` 仍依赖 CDN（lucky-canvas 与字体）。如需完全离线，可把 lucky-canvas 与字体一并内联进单文件。
